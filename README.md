## Oyun konsepti

Oyuncuya üç kartlık bir deste verilir ve bu kartlarla rakibine karşı mücadele
eder. Kartlar kullanıldıkça değişir; hangi kartı ne zaman oynayacağına karar
vermek oyunun strateji tarafını oluşturur.

Demo sürümünde oyun çevrimdışı oynanır: rakip, Python ile yazılmış bir yapay
zekâdır.

## Kartlar

Demo sürümünde üç çeşit kart var:

| Kart | Etkisi |
|---|---|
| **Saldırı** | Temel saldırı |
| **Savunma** | Temel savunma |
| **Sersemletme (stun)** | Özel etki |

## Kullanılan teknolojiler

| Katman | Teknoloji |
|---|---|
| Arayüz | Fragment, ViewBinding |
| Gezinme | Navigation |
| Yerel veri | Room |
| Yapay zekâ rakip | Python |
| Yaklaşım | Nesne tabanlı programlama |
| Geliştirme ortamı | Android Studio |

## Tasarım ve görseller

Oyun görselleri yapay zekâ ile üretildi; bunun dışındaki tasarım ve düzen bana
ait. Kodlama sürecinde yapay zekâ destekli araçlardan yararlandım.
